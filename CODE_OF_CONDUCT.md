# Code of conduct

## The short version

Be decent to each other. Assume good faith. Critique code, not people.

## What that rules out

Harassment, personal attacks, discriminatory language, sexualised content,
publishing someone's private information, and sustained disruption of
discussion. None of it is welcome here, in issues, pull requests, commit
messages, or anywhere else this project happens.

## Scope

This applies in all project spaces, and when you are representing the project
in public.

## Enforcement

Report problems privately through GitHub's report feature, or by opening a
private security advisory if you would rather it not be public. Maintainers
will read it, and will not name the reporter.

Maintainers may edit, delete or reject comments, commits, code, issues and
pull requests that do not fit, and may temporarily or permanently ban anyone
for behaviour they judge inappropriate, threatening, or harmful.

Maintainers who do not follow this in good faith may face consequences decided
by other maintainers.
